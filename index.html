Yang sudah berfungsi

Vectorizer SVG/EPS path contour tracing, upscale canvas, hapus warna latar, pattern tiling, gradient PNG/SVG, stock checker dasar, metadata draft, batch ZIP, export format, palet warna, dan crop/rotate.

Batasan teknologi

Vectorizer v5 membentuk path poligon dari kontur piksel (bukan kurva Bézier). EPS adalah ekspor dasar dari path tersebut; detail kecil dan kontur kompleks tetap perlu diperiksa. Upscale bukan AI. Background remover tidak mengenali objek. Metadata helper memakai kata dari deskripsi, bukan AI cloud.

Perubahan v7.0

AI Metadata Studio dapat memanggil Gemini melalui endpoint backend /api/metadata. Secret API disimpan di Cloudflare Worker; browser tidak menerima API key. Metadata Audit dan seluruh fitur lokal v6 tetap tersedia.

Adobe Stock

Tidak ada alat yang bisa menjamin karya diterima. Pastikan karya orisinal, tidak melanggar hak cipta/merek, tidak mengandung artefak, dan ikuti ketentuan file serta metadata terbaru dari Adobe Stock.

Untuk AI metadata, deploy folder ini sebagai Cloudflare Pages project dengan Worker Functions di folder functions/. Tambahkan GEMINI_API_KEY sebagai secret di pengaturan Pages. Fitur AI memerlukan koneksi internet dan kuota API; fitur lokal tetap bisa digunakan tanpa AI.
